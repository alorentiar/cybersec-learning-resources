# Network Security

Keamanan jaringan: protokol, analisis trafik, pertahanan perimeter, dan arsitektur.

---

- [NIST SP 800-41 Rev. 1](https://csrc.nist.gov/pubs/sp/800/41/r1/final) — Guidelines on firewalls and firewall policy for designing, selecting, and maintaining network security controls. _(01 Oct 2026)_
- [NIST SP 800-77 Rev. 1](https://csrc.nist.gov/pubs/sp/800/77/r1/final) — Official NIST guide to planning, implementing, and maintaining IPsec VPNs for network security. _(02 Oct 2026)_
- [Nmap Network Scanning](https://nmap.org/book/) — Official Nmap book covering network discovery, port scanning, OS detection, and security auditing techniques. _(05 Oct 2026)_
