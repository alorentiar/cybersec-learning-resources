- [NIST SP 800-115](https://csrc.nist.gov/pubs/sp/800/115/final) — Official NIST technical guide for planning and conducting information security testing, assessments, and penetration testing. _(23 Sep 2026)_
- [MITRE ATT&CK](https://attack.mitre.org/) — MITRE ATT&CK is a globally accessible knowledge base of adversary tactics and techniques based on real-world observations. _(24 Sep 2026)_
- [GTFOBins](https://gtfobins.github.io/) — Curated Unix binaries that can be abused for privilege escalation and bypassing local security restrictions. _(17 Oct 2026)_
- [Exploit Database](https://www.exploit-db.com/) — Public archive of exploits and vulnerable software for penetration testing and security research. _(23 Oct 2026)_
