# Web Security

Keamanan aplikasi web: kerentanan umum, teknik eksploitasi, dan cara mitigasinya.

---

- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — Official OWASP ranking of the ten most critical web application security risks, with guidance and remediation advice. _(21 Sep 2026)_
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — Free official PortSwigger learning platform with interactive labs covering web security vulnerabilities and exploitation techniques. _(22 Sep 2026)_
- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) — Official OWASP guide for testing web application security across the software development lifecycle. _(25 Sep 2026)_
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) — A comprehensive collection of OWASP application security cheat sheets covering secure design, authentication, input validation, and defensive coding practices. _(26 Sep 2026)_
